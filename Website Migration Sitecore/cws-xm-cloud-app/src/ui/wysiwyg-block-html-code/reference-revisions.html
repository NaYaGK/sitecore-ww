CWS Repair App

L'application CWS Repair permet aux clients de nous envoyer des demandes de réparation par le biais de l'application - sans aucun enregistrement.

Voici comment cela fonctionne : l'application est téléchargée dans l'App Store d'Apple ou dans le Play Store de Google, puis le code-barres du vêtement de travail est scanné et le type de réparation est sélectionné et envoyé. Une indication de réparation est alors créée dans l'outil client CWS et transmise à la blanchisserie. La prochaine fois que le vêtement concerné sera envoyé au lavage, il sera réparé.
